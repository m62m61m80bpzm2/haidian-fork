# 749收容漫剧 · 第1-2集

番茄小说《大一实习，你跑去749收容怪物》第1-2章 竖屏漫剧改编（都市玄学收容流）。

## 成片
| 集数 | 片名 | 时长 | 规格 |
|------|------|------|------|
| 第1集 | 血石 | 92.6s | 1080x1920 / 30fps / H.264+AAC |
| 第2集 | 罔象 | 100.0s | 1080x1920 / 30fps / H.264+AAC |

成片位于 `07_成片/`。

## 目录结构
- `02_角色资产/` 角色设定图（标准图+三视图）
- `03_场景资产/` 场景标准图
- `04_分镜成图/` 全部分镜图（76张）
- `05_动态片段/` 图生视频动态片段（37条，Agnes 双模型并行管线）
- `06_音频/` 配乐与音轨
- `07_成片/` 最终竖屏成片（2集）

## 制作管线
分镜成图（Agnes 2.5flash）→ 图生视频（2.5flash竖屏 / 2.0flash横屏转竖屏）
→ ffmpeg 模糊垫底竖屏化 → 字幕烧录 → 拼装成片。
