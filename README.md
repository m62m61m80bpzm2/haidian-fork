# 三国名场面 · 竖屏短剧

AI 短剧流水线作品：**《辕门射戟》《三英战吕布》** 两集，各 6 镜 × 10s ≈ 60 秒，竖屏 720×1280。

## 成片
- `辕门射戟.mp4` / `三英战吕布.mp4`（根目录）
- 每镜首帧锁定关键帧 → Agnes keyframe 模式生成 10s 单镜头（原生同期声，台词口型同步）→ 逐镜归一拼接

## 流水线（五文档方法论）
剧本（场次+台词+SFX+连续性）→ 视觉设定（锁面）→ 分镜（唯一职责/起点/终点）→ 图片提示词（出关键帧）→ 视频提示词（出片段）

## 目录
- `辕门射戟/` `三英战吕布/`：各集五文档
- `制作成果/关键帧/`：12 张首帧关键帧（720×1440）
- `制作成果/视频/`：12 段镜头素材

## 技术栈
- 关键帧：z-ai image（720×1440）
- 视频：agnes-video-2.5-flash（keyframe 模式，9:16）+ z-ai video 备用通道
- 原生音频：台词直接写入视频提示词，口型同步，无后期配音
- 拼接：ffmpeg（scale→trim→concat→fade）
