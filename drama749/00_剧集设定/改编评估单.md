# 《大一实习，你跑去749收容怪物》漫剧改编评估单（阶段0）

## 素材来源

用户提供番茄小说《大一实习，你跑去749收容怪物》第1-3章（都市玄学收容流男频爽文，主角陆鼎）：

- **第1章「等了二十年的金手指，终于有能用的希望了」**：穿越十九年、金手指始终不亮的孤儿大学生陆鼎，为赚实习学分和工钱入职地质勘探工地。临近发工资，工地挖出破损渗血的石球，工人们当成"太岁"议论纷纷不敢碰，陆鼎借"八字硬、有本事"说服项目经理罗安平拍板，抡起冲击钻直接开钻。
- **第2章「收容南山顽石，得斤车之道无物不斩」**：钻破石皮，石球上镶嵌的双眸猛然睁开，全场工人吓得逃散，唯独陆鼎兴奋冲锋。钻爆石球后，金手指【怪物收容监狱】激活，收容"南山顽石"，获得奖励"斤车之道"（无物不斩）。罗安平服气，当场转账两万奖金。随后749局（国安编制）一男一女两名干员堵住罗安平问话，超清监控回放令二人震惊，警告封口后离开。
- **第3章「再杀怪物罔象，得忘形之谓，天人合一」**：陆鼎回安置房收拾行李准备搬家，在阳台瞥见小区竹林里的人影正在"数"自己住几楼。陆鼎叫阵"有种上来"，发现来者不是人是罔象，兴奋迎敌。楼道声控灯下试斩（削铁如泥、铁质扶手应声而断），看清罔象真容（两米余高、黑毛包裹、脸似枯面具、双眼幽黄）。两记无形斩击将其斩杀于楼下空地（上半身与腿分离、碎成四大块）。收容罔象，获得"忘形之谓"（炁开天窗，忘人忘我，天人合一）。749二人组恰好赶到楼下，目击小黑点从天而降，彻底震惊。

## ① 这一集讲什么（一段话概括）

穿越十九年金手指始终不亮的大学生陆鼎，在工地实习的最后一夜等来了转机：工地挖出的石球会流血、会睁眼。全场吓跑，他反手抡起冲击钻把它钻爆，激活【怪物收容监狱】，收容南山顽石获得"斤车之道"，从此无物不斩。当晚回到安置房，又有一只罔象摸上门"数楼层"，陆鼎叫阵迎敌，楼道试斩、楼下收割，两击斩碎罔象再收一奖（天人合一）。而他不知道的是，749局的干员已经顺着监控找上门——楼下空地，两人抬头，看着他从天而降。

## ② 黄金3秒钩子（选定的情节点）

选择**反常事件式（模板12）+ 金手指降临式（模板8）复合开场**：

- 冷开场画面：夜色工地，冲击钻怼上石球 → 鲜血喷溅 → 石球双眸睁开 → 陆鼎逆着逃跑的人流冲锋，狂笑喊出"会流血，就能弄死！"
- 为什么选它：①反常度极高（石头睁眼）+ 反差极强（众人逃、主角笑），3秒内完成"谁+在什么反差里"；②人声开场（陆鼎台词），符合手册01"禁止风景空镜开场"；③1-2个分镜即可画出，画面成立。

## ⑤ 取舍建议

**删**：
- 第1章大段穿越来历与心理独白 → 压缩为2镜快闪（面板文案+一句台词交代"十九年金手指不亮"），不做整段闪回。
- 南山顽石的古籍渊源（秀才求梦故事）→ 压缩为收容面板上的一行文案，不还原古籍场景。
- 陆鼎挑工作的求职细节 → 删，用一句台词"干了快一个月就等这个"带过。

**强化**：
- 石球睁眼瞬间的恐怖感 vs 陆鼎兴奋笑脸的**反差**——这是本集记忆点，按手册10电影级质感写。
- 斩罔象动作戏：按手册12节拍三段式切镜（交锋单镜1-2秒），力量用效果词表达。
- 749二人组的反应镜头贯穿首尾（前段问询罗安平、后段楼下目击），形成"被盯上"的主线钩。

**新增转写**：原著大段内心戏转写为【怪物收容监狱】面板的视觉化呈现（系统面板图+简短播报音）+精简台词，符合"能用画面表达的不用台词"。
